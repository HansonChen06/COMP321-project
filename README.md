# The Unreliable Guide

This directory includes the problem statement, test data, 
a C++17 test-case generator, input validators,
and accepted and wrong-answer submissions.

## Repository layout

- `problem_statement/`: English LaTeX problem statement.
- `data/`: sample and secret `.in`/`.ans` pairs.
- `input_format_validators/`: strict syntax and semantic input validator.
- `submissions/`: categorized reference and intentionally incorrect solutions.
- `test_case_generator/`: deterministic C++17 data generator.
- `presentation/`: presentation deliverables.
